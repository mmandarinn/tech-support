# SIGN Support Telegram Bot

Telegram-бот для связи пользователей с командой технической поддержки SIGN. Бот принимает сообщения от пользователей, пересылает их в закрытый чат поддержки и позволяет администраторам отвечать прямо из этого чата.

## Возможности

- Прием обращений: Пересылает текст, фото и документы от пользователей в чат поддержки.
- Защита от спама: Ограничивает частоту обращений. Пользователь может писать не чаще, чем раз в 6 часов.
- Ответы через Reply: Администраторы могут отвечать пользователю с помощью функции "Ответить" (Reply) в Telegram.
- Блокировка пользователей: Команды для добавления спамеров в черный список.
- Работа только в ЛС: Бот игнорирует сообщения из групповых чатов.

## Требования и установка

Для работы проекта нужен Python 3.x и библиотека pyTelegramBotAPI.

Установка зависимости:
```bash
pip install pyTelegramBotAPI
```

## Настройка и запуск

1. Откройте код бота.
2. Вставьте токен вашего бота от @BotFather:
   ```python
   bot = telebot.TeleBot('ВАШ_ТОКЕН', skip_pending=True)
   ```
3. Вставьте ID вашего чата поддержки:
   ```python
   SUPPORT_CHAT_ID = str('ID_ЧАТА')
   ```
4. Запустите скрипт:
   ```bash
   python main.py
   ```

## Инструкция для администраторов

- Как ответить пользователю: Сделайте Reply (Ответ) на техническое сообщение бота вида "Сообщение от [ID]" и напишите: `/answer Ваш текст`. Бот сам перешлет этот ответ пользователю.
- Как забанить: Сделайте Reply на сообщение с ID пользователя и напишите `/ban`.
- Как разбанить: Сделайте Reply на сообщение с ID пользователя и напишите `/unban`.

## Важная особенность

Список забаненных пользователей и таймеры ограничений хранятся в оперативной памяти. При перезапуске бота эти данные сбросятся.
